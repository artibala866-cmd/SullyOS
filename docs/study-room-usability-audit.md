# 学习室原始目标复核与流畅度审计（2026-10-29）

## 要解决的不是换皮，而是最短可用路径

原目标是「专注 / 画师排单 / 课程表 / 原自习室」同一入口，
Char 根据当前用户主动打开的场景帮助，不自动打断日常私聊，
本地旧数据兼容，所有远端任务严格依照 AMSG 2.0 和显式授权。

| 原始目标 | 当前代码 | 仍要处理的实际使用问题 |
| --- | --- | --- |
| 安静可靠的番茄钟 | 绝对截止时间、暂停/恢复、中断不结算、专注记录和按 5 分钟交流配额已存在 | 本轮排除编辑区 0.5 秒全量重绘；还需 Android 返回/后台长时间实测 |
| 自习室教材、PDF、章节与题目 | 继续复用 StudyApp，未替换 StudyCourse | 大型教材的真机内存和返回状态仍待实测 |
| 手动画稿排单与 Char 建议确认 | 委托、工时、阶段、截止风险、预览后勾选应用已存在 | 本轮优化 N 件委托每件重复计算整段日期的性能；长期仍缺可调整的每日真实日程时间块 |
| 报班课程、作业和笔记 | 课程表、图片识别预览、作业笔记、旧教材 ID 关联已有 | 本轮课程编辑改为本地草稿+显式保存，防止每次输入都访问 IndexedDB；课表仍须实际图片回归 |
| Char 应用内按需帮助 | 现有应用内对话和分类上下文 | 真实用户 API 使用时仍要测错误重试、长回答和键盘遮挡 |
| 私聊隐私和到点提醒 | 按 Char 学习/排单授权及固定 AMSG 2.0 提醒已接入 | 远端取消失败状态尚需真实账号核对；不自动触发收费 API |

## 本轮依据代码确定的卡顿与丢状态来源

1. `apps/ScheduleApp.tsx` 在任何标签下每 500ms 更新 `now`，原来会带动 800+ 行的 `WorkspacePanel` 重绘；本轮仅显示计时/弹窗时按 1 秒刷新，其它标签只安排单次到点唤醒。
2. `calculatePlanRisks` 原来在每张委托内重复计算从今天到交期的整个课程/作业容量，属于多重扫描；本轮统一预计算到最远交期的每日容量前缀。
3. 进入排单、课程表、自习室时原来会卸载编辑区，新增课程/委托草稿和图片识别预览可能丢失；本轮同一个 WorkspacePanel 挂载一次并隐藏复用，进入自习室时也保留。已展开的单项课程/委托编辑器是独立的临时草稿，切换区块前仍需先保存。
4. 课程表字段原本每键入一个字符就发起事务写库；本轮使用独立课程编辑表单，点击保存一次提交，不自动触碰旧教材或其它课程字段。
5. 切换页面时主滚动位置不稳定；本轮按标签保留滚动位置。

## 守住的边界

- 不改变 `master`、原私聊提示词/世界书/角色卡、原自习室教材结构、旧番茄钟数据键、AMSG Worker。
- 不清空本地数据库；保存仍使用既有 `mergeWorkspaceLocalEdit` 和 `mutateWorkspace` 原子保护。
- 不因单元测试通过就宣称 Android 真机、收费 AI 或锁屏推送已通过。

## 后续优先级

1. **真人操作路径和手机适配**：真机验证键盘、安全区、返回、跨页保留草稿和异常恢复；解决实际反馈的阻塞点。
2. **排单可执行性**：把「预计剩余分钟」分配到明确每日可用时段，排班冲突和缓冲精确到天，AI 仅给可编辑方案。
3. **作业/课程实用性**：补课、请假、周次和日期范围，笔记检索与自习室章节直接发起专注。
4. **提醒与备份验收**：AMSG 远端创建/取消/改期、应用重新安装/备份恢复及旧数据记录比对。
