# 快捷导航与返回

「悬浮球设置」与其他设置板块一样默认折叠，展开后显示开关和 App 槽位。从悬浮球的「自定义」或空槽位进入时，自动展开并滚动到此板块；收起板块不改变已保存的开关或槽位。

设置内的「悬浮球复位抢救」只移除位置记录，并即时将已显示的球放回容器右下方的默认安全位置、收起菜单、结束拖动；保留开关和 4 个槽位。关闭状态也可复位，下次开启按默认位置显示。存储不可用时至少复位当前页面。独立的一次性「悬浮球来了」公告排在已有更新队列最前面，沿用数据就绪／解锁／启动提示的门禁；只有关闭、知道了、去设置才标已读，去设置定位并展开本板块，不自动开启球。公告不引入网络请求或新的启动等待。

设置顶部提供「悬浮球设置」，默认折叠，悬浮球开关默认关闭。开启后在未锁屏的界面显示：40px 半透明、可拖动的小球，打开为靠近小球的 iOS 风格磨砂浅色列表，包含「切换 API」「上一级」「回到桌面」、已经配置的自定义槽位及「自定义快捷入口」。空槽位不占面板位置，但仍可在设置里配置；面板宽度上限 232px、高度上限 288px，安全区内定位，内容过多内部滚动。设置也是可选槽位，不占固定按钮。槽位通过分层搜索选择器配置，可留空；「自定义快捷入口」定位到悬浮球设置。使用桌面 App 清单，排除开发专用入口，不暴露隐藏／旧入口。开关、位置、槽位只保存在本机独立 localStorage key，不修改主题包、聊天或主库 schema。关闭时不挂载拖动、尺寸观察或展开菜单的监听；配置槽位不提前加载对应 App，只有点击才导航。

悬浮窗「切换 API」直接展示同一套全局 API 预设（`findActivePresetId` 标识真正使用中的条目）；点选调用 `configFromPreset`，通过 `updateApiConfig` 持久化 URL/Key/Model 整套配置，并与设置页一样调用 `syncAmsgLlmCredentials` 更新主动消息凭据。悬浮窗的「手动填写」可编辑主对话 URL、Key、Model，保存后不跳页面；专用语音、识图、角色独立及 App 独立 API 不随之覆盖。只有点「完整设置」才经 `utils/settingsNavigation.ts` 定位设置的 API 折叠区域；不重载设置，也不重置未保存的草稿。磨砂面板依容器安全区定位，矮屏可滚动，减少运动设置下关闭展开动画。

悬浮球在拖动开始时读取容器边界和安全区，移动过程不做 DOM 尺寸读取，不写存储；结束时保存位置。重新开启、窗口大小或键盘导致容器尺寸变化时重新约束位置。音乐悬浮球保持原有播放控制用途。

槽位以 App ID 和可选的稳定目标 ID 保存。3D 家园、Message 和神经链接可指定角色，所有分层入口也可只打开首页／列表。原 v1 的三个 App 字符串兼容读取为入口对象，第 4 个槽位补空，不改主库 schema。显示名仅作提示，路由始终按 ID；已删除角色提示重新配置，旧家园世界槽位显示为空，旧小小窝槽位保留原角色并打开 3D 家园。

其他入口按 `utils/navigationShortcuts.ts` 的目录展示，必须有对应 App 接收逻辑才加入目录：

- 神经链接：设定、记忆、印象、门牌、手办柜、统计 → 角色。
- 电话：通话准备 → 角色，或通话记录；不自动拨号，进行中的通话不会被快捷入口切换。
- 见面：准备、设置、记录 → 角色，或剧情剧场；准备入口不清除已有见面存档，不生成开场。
- 记忆宫殿：房间、像素家园、全部记忆、记忆盒、角色设置 → 角色，或全局设置；不自动启用宫殿。
- 交换日记、自由活动、攻略本可选角色，分别进入日历、角色主页和攻略准备。
- 音乐：主页、搜索、播放页、设置，以及角色音乐角落 → 角色；不自动播放。
- 群聊、世界书可选已有群组／条目；写歌可选乐谱或指定伙伴的新建表单。配置时只投影内存中已有的标题和 ID；删除的目标提示并回原 App 列表，不换成其他内容。
- 外观、Spark、学习室可选现有标签页。学习室直达仍遵守专注保护。

`appShortcutLaunch` 在进程内传递请求，按 App 消费一次，支持 App 已打开时的重复导航；React StrictMode 不重复应用请求。异步读取通过当前请求标识拒绝已退出／后续快捷请求的旧结果。不同 App 之间不串目标，不通过强制重挂载来清空 App。没有细分导航的 App 保留直接打开入口。`entryId` 只接受目录中的枚举，角色和内容 ID 只允许匹配的目标类型；显示名不能影响路由。

`NavigationSlotPicker` 点击槽位才懒加载，支持 Unicode 宽度／大小写归一化、多关键词搜索和延后过滤；固定 68px 行只挂载可见区域和少量缓冲，不加载角色头像或 3D 预览。取消或返回不写槽位。选择器打开时暂时隐藏悬浮球，避免挡住搜索框，关闭后恢复原位置。`roomLaunch`、`characterLaunch` 支持已挂载 App 订阅；3D 跳转仍走原入住定义／形象检查，不走 2D 房间初始化。选入口本身不生成房间、不请求模型，点快捷入口后保持原 App 的进入行为。

「返回上一级」、浏览器返回、Android 返回共用 OSContext.handleBack。「回到桌面」直接使用 closeApp。美化页面通过 useLocalBackHandler 接入：先处理打开的确认窗、预览或编辑面板，再返回装扮列表／外观设置；只有 App 顶层才走关闭 App 的默认逻辑。保存或领取进行中继续遵守已有的禁止退出条件。

局部返回层级：装扮入口 20、编辑或分享子页 30、导入预览 35、装扮预览 40、确认窗／预设选择器 60。子层比父层高；相同层级按最近挂载顺序处理。hook 用最新回调但保持注册顺序，卸载后移除自己，不覆盖其他面板。没有处理者时仍执行原 App 返回处理及关闭逻辑；普通外观标签不是嵌套子页，保持原有返回行为。
