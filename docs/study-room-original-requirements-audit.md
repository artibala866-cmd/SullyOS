# 学习室 · 回归最初需求的可用性审计（2026-10-29）

本文件严格对照用户最初的 17 部分开发指令，而不是“界面做完了”的主观完成度。
工作分支只有 `remove-checkphone-vrworld-lifesim`，不修改 master。
不创建第二套自习室、角色聊天、提醒服务或客户平台。

## 本轮真正修复的操作阻塞

- **画师排单入口太深**：原先排单打开先显示容量/复杂月历，而可直接操作的委托都藏在「全部委托」折叠层。现在优先显示可绘制的三张画稿（保持用户手动队列顺序），每项直接「开始画」或「调整」，展示阶段、交期、预计工时和既有风险。等待客户确认/暂停/已交付项目不会冒充今天要画的任务。月历与完整记录仍保留。
- **快捷按钮原本需要再点一次播放**：从画稿或作业点击「开始画／开始学」现在会使用当前设定的专注分钟直接创建并启动本轮计时；如果已有进行中的专注或休息则不会覆盖。\n- **课程作业需要反复选课**：原先先浏览周日历、课程表管理、再下滑到「选择课程」才能看到作业。现在课程表首屏列出按截止时间排列的四项待做作业，直接「开始学」或定位原课程；其他作业可展开。进入课程后默认选择今天正在上课的有效课程（否则第一门有效课），新增课程后直接定位作业区。未归属作业仍能开始学习，不会自动删除或改动归属。
- **从原自习室返回位置不对**：曾经从任意入口进入旧自习室再返回常被送回计时页。现在正常入口回到进入前的排单/课程/专注区域；从课程关联打开旧自习室则返回课程表。旧 StudyApp 资料、章节、练习册不移动。
- **委托编辑一打字就落库**：旧版在每个输入控件的每次变更里执行 `patchCommission` → IndexedDB transaction，容易出现高频保存、输入迟滞和操作后不知道是否保存。现在委托编辑组件为本地草稿，只有点击「保存修改」才提交具体变更字段。取消不写入；同字段并发冲突由原有乐观校验机制拒绝，避免覆盖另一个窗口的新值。改成暂停/交付/取消/归档时沿用既有 AMSG 取消流程，失败明确提示；不自动向客户发消息。

## 对照原始需求，实际还存在的缺口

| 原始要求 | 当前事实和剩余工作 |
| --- | --- |
| 统一入口与番茄钟简洁 | 已有四区导航、原 StudyApp 兼容和专注计时；本轮没有把日历塞进倒计时页。仍需 Android 后退键与小屏手测 |
| 番茄钟可靠恢复与 5 分钟聊天额度 | 有 sessionId、前端倒计时恢复和每窗口上限；需真实关应用、切后台/重开/暂停/中断端到端核查 |
| 画师排单信息和阶段 | 有个人委托、自由文本阶段、优先级、截止、剩余工时、专注关联和日程；**仍缺按自定义阶段分别安排工时、审核和修改缓冲的完整执行队列** |
| 手动排单与时间冲突 | 手动顺序、日程和容量缺口已有；仍不能像小时级日历那样明确安放每个画稿/作业阶段，超载提示不等于排好了 |
| Char 排单建议 | 需用户主动发起、预览并逐项确认；仍需真实模型输出、错格式及状态竞态人工验收 |
| 现实课程表和上传识图 | 周期性课程录入、识图预览并人工校对已有；**单次调课/请假/补课、课程附件与日期例外处理还不完整** |
| 作业笔记与原自习室 | 有作业、笔记、PDF 教材学习、原章节/练习和关联入口；操作路径本轮缩短。仍需作业附件与真实旧备份恢复走查 |
| Char 应用陪伴与私聊权限 | 应用内角色/用途/事项隔离与手动学习复盘已有；独立的私聊学习/排单授权开关存在，默认关闭。不能据此称真实 AI 提示词完全验证 |
| AMSG 2.0 定时提醒 | 复用原定时任务、核查身份、撤销失败提示；**实际推送/时间改期后的完整远端同步、过期提醒处理必须继续验收** |
| 隐私、备份与旧记录 | 本地 workspace、旧 pomodoro 和 StudyCourse 不迁移；事务保存及损坏备份保护已存在。真实整机备份还原、跨设备、多标签页压力测试未完成 |
| 视觉与移动端可用性 | 黑白灰、简单计时页保留；本轮改操作层级，不做装饰性美化。Android 设备、键盘遮挡、系统返回和性能仍需验证 |

## 下一轮安排（坚持最初任务范围）

1. 画稿阶段任务化：允许用户定义/跳过阶段、估计该阶段剩余时间、明确等待客户确认与自己绘制的区别，并能从阶段开始专注。
2. 课程的日期例外：手动标注调课、请假、补课、停课；不要只靠每周重复课程覆盖真实课表。
3. AMSG 到点提醒的编辑/完成/取消关联复验；避免改期旧提醒继续出现。
4. 每项新增功能同时检查旧存档兼容、权限边界、定向测试/TypeScript/构建，后续安排真实 Android 体验核查。

**不得将自动化测试、生产构建或本轮 UI 修正表述为全部产品功能已完成。**
