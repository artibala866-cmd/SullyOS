# 二号素体 · 家具动作适配清单

当前记录：2026-10-01。以已存在的家具互动为范围；“接入”表示可以在二号骨架上播放并完成互动流程，不等于所有衣服、身高与家具组合都经过人工验收。

## 本轮补齐

| 入口 | 二号行为 | 验收入口 |
| --- | --- | --- |
| 赛车架 + 电竞椅 | 寻路到椅旁、入座，双手握住实测轮缘、拇指朝上；轮圈/轮毂与双手绕同一倾斜轴转向；结束保留坐姿 | 对照页「赛车」 |
| 圆环音游左右机位 | 双脚站稳，双手错开半拍、约每 0.3 秒换键；按真实臂展选择可达键，不同高度独立拍键，掌面接触与亮键同钟 | 对照页「圆环音游」 |
| 餐桌 + 已吸附餐椅 | 寻路入座，保留选择的座位；抬勺送到下脸前，勺子跟随真实手骨 | 对照页「餐桌」 |
| 四款可抱玩偶 | 双臂接触玩偶两侧，抱持高度随胸口和坐/站姿调整；放回恢复原实例 | 对照页「玩偶」 |
| 原单人床、双人床、上下铺、高架床 | 接入已选 Meshy 01 睡眠，按床的真实朝向定位头部；单/双人床使用床边进入/起身流程 | 对照页「旧床验收」下拉选择 |
| 已登记座位的矮凳/座椅 | 保留臀部接触点，用现有腿部 IK 防止脚底穿地；花瓣坐垫保留专用姿势 | 对照页「座椅验收」下拉选择 |

新动作沿用 48 骨，虚拟 IK 目标不加入蒙皮骨架，不拉伸骨长。赛车/音游/吃饭/抱持是项目内的接触适配，没有新增下载动画；睡觉继续复用用户已选的 Meshy 动作及原来源记录。

`furnitureMotion.ts` 管理四类互动的手部目标；`blankMotion.ts` 管理肩臂预备、坐姿和动作复位。活动坐标沿用原 `.7` 比例，在 `visitor.ts` 统一换算为二号当前缩放。二号音游取消蹲跳，站位稍靠近机台；原版小人保留原跳跃。按钮与机台不缩放。餐具仍使用原临时效果对象。

进入布置会停止设备互动并清掉临时餐具/效果；切换角色、休息、动作自然结束的清理已检查。家具与角色存档不增加临时动作数据。餐桌走近后的活动重新查询包含 `stationId`，避免用户选后侧却入座前侧。

## 仍属于独立后续制作的内容

- 上下铺/高架床保留原来的直接就位和离开，没有新增爬梯动画；高架床护栏也不被当成可穿越的入床路径。
- 拾取玩偶前的走近、弯腰，以及音游机前的完整走近流程仍沿用旧入口行为。本轮补的是抱持/游玩动作。
- 瑜伽上下垫、低门洞低头通行、多居民排队/占位、通用衣物碰撞仍不是现有完整能力。
- 书柜、打印机、电视/游戏主机等只有静态摆件能力的家具，不因本轮适配而新增读书、打印、看节目等玩法。

### 拥抱动作细化（2026-10-03）

二号拥抱新增独立抬臂前摇、回应方延迟 0.22 秒、绕身体两侧收拢的手部轨迹；抱稳后主动方右手轻拍两次，对方左手回拍一次，另一只手保留支撑。掌面朝向对方背部，落点外移到背部表面；躯干轻微呼吸并随拍背回应，结束先松臂再垂手。所有动作按绝对动画进度采样，不累计 IK，暂停/拖动进度可重现。

测试页默认选中拥抱，进度条涵盖走近所需时间，可拖到完整收尾。新增真实骨架回归检查：前摇抬手、单手离背/回落、另一只手保持支撑、反复跳帧与阶段边界连续。

### 拥抱手型细化（2026-10-03）

新增 hugHands.ts：手指沿背部斜向横放，手腕由抬手时的侧向姿势渐转为贴背；修正当前素体手掌朝向（弯指朝 -Y，+Y 是手背）。五指使用独立的近端/末端弯曲，略收指缝；拇指单独内收，无名指与小指弯曲更明显，拍背时只适度展开，落回再放松贴合。掌根接触目标留出弯指余量。

接触求解的 curl 可省略，让独立手型保留 idle 的手指基准，避免权重归零时被强制拉直。新增真实骨架测试验证掌心朝背、指向横置、左右手指尖间隔、单手拍背开合及结束恢复原手型。

### 正式互动与手机绑定（2026-10-03）

亲密分类首组展示「拥抱、公主抱、被公主抱」，保留其他已选互动。home-princess-carried 是独立菜单动作，共用抱持实现，在会话开始时交换抱人方/被抱方；原版 Chibi 隐藏两种公主抱，运行时也校验体型。日常记录按真实语义写「你被某某公主抱」。

本轮验证：5 个相关测试文件共 33 项通过；互动试验页与家园验收入口联合构建通过。浏览器检查了被抱角色反转与两个手机动作的手部道具位置。

### 双人互动入场/收尾转圈修复（2026-10-03）

导入动作原先分别插值人物根节点朝向与骨盆朝向，结束时两次绕 Y 轴旋转会叠成大圈。单手搭肩复现中，约 19 度的收尾变成约 341 度。motionHeading.ts 将捕获骨盆拆为水平朝向与倾斜，前者只在根节点做一次最短转向，后者仍由骨架混合；动作进行中两者相乘保留原始姿势，拉手转圈等原有旋转不删除。Chibi 的点位式手臂同时转换到去除朝向后的局部空间，接触判断仍用原始双人坐标。新增全体导入双人动作首尾轨迹测试与源旋转重组检查。

验证：35 项相关测试及家园/动作页联合构建通过；浏览器逐项采样 7 个关心照顾动作的进入和收尾，单手搭肩收尾约 19.09 度，未再出现叠加整圈。揉肩等背向站位仍保留必要的半转身。

### 手机托持手修正（2026-10-04）

更正上一轮一律绑右手的处理：源动作 review-phone（看手机）左手稳定托持，右手点屏；以躯干为参照采样 2–8 秒，右手移动路程约为左手的 8.5 倍。现在按动作显式配置托持手：看手机用 L，world-afk-texting（低头发消息）用 R，后者左手自然垂下。屏幕方向随左右手镜像；原版 Chibi 的道具定位也共用该配置。回归测试验证操作手独立运动不会带走手机。

### 床上清醒动作（2026-10-04）

二号床位新增「躺着说话」「躺着玩手机」「侧躺」，从床的家具动作环或上床后的小人面板选择。沿用现有床边寻路、坐稳、躺下和起身；高床保留原有直接就位规则。三个动作在 Meshy 睡眠末帧上叠加项目内编写的骨骼姿势，未导入新的外部动作。

躺着说话保持睁眼、轻转头和低幅度手势；真实家园聊天也可在二号床位上交谈，结束恢复原床上状态。手机由左手稳定托持，屏幕朝向头部，右手食指单独点屏；手机只属于临时动作，切姿势/起身时释放。侧躺绕骨盆转身、双腿错开屈膝、双手自然放在身前。姿势切换与起身前转正使用 1.2 秒过渡，不改骨长或家具存档。

验收入口：`test/fixtures/room3d-body-comparison.html?room=beds&body=blank`，动作页也新增直达链接。单元检查涵盖床位菜单、80%/100%/125% 身高、床朝向、托持手稳定、操作手动作、跳帧可重现及侧躺切换连续性。原版 Chibi 暂不展示这三个动作。

### 一坐一站的拥抱（2026-10-04）

二号「拥抱」在一方坐着时使用 seatedHug.ts：站立方先屈膝跪下，再侧头靠近腰腹、双手分别环住腰的两侧；坐着的一方先抬手迎接，抱稳后慢慢摸头，空闲手放在自己身侧偏后。结束先松臂，再起身，座位与坐姿不变。双方身份交换走同一流程，现有寻路/空间检查保留。

按近景反馈修正手部拥挤：环腰双掌沿左右腰侧朝后，不在中线交叠；去掉穿过大头附近的额外扶背目标，空闲手改放身侧；摸头先于环抱到位、晚于松臂撤回，避免过渡时经过另一人的手。沿用原48骨与固定骨长。骨架测试覆盖三档身高组合、角色交换、膝/脚不穿地、固定坐位、手掌间距、摸头变化及取消恢复。独立互动页增加「拥抱姿势」选择，`?seated=character` / `?seated=user` 可直达。
