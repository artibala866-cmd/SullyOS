# 真人感、角色手机与日程的移植复核

复核基线：`6236724c`，只在 `remove-checkphone-vrworld-lifesim` 增量修复。参考仍为用户提供的 MarshmallowMachineNext v0.1.0-next.61 APK，不恢复退役 CheckPhone、VRWorld 或人生模拟。

## 目前适配范围

| 能力 | 当前状态与职责 |
|---|---|
| 输入结束接话 | 已适配真实发送、连续消息合并、草稿/IME/键盘门禁、授权代次、取消及迟到拒收；不是靠周期计时产生新话题 |
| 私聊和角色手机 | 手机 NPC 对话不代答 User；复用选定私聊历史范围、人物、世界书和允许读取的记忆，保留手机任务自身 JSON 合约 |
| 日程联动 | 已有只读计划背景。本轮消除“正在做”的事实断言，关闭日程后手机不再读取旧计划；不因睡觉/忙碌计划强行终止正在进行的聊天 |
| 手机经历回流 | 已有存档事件进入普通私聊。本轮统一近期、同角色、非未来事件及角色时区；关闭时间感知不额外添加钟点。旧事件仍在原存档，未删除 |
| 手机独立后台 | 保留手机自身许可、机会判断、预算、互斥与内容删除检查；本轮补请求层中止和上下文准备阶段撤权检查，不从真人感开关推导新付费许可 |
| 棉花糖完整主动联系 | 尚非等价：其完整主动话题、追话/分段编排、生活活动引擎未整体移植。现有每日联系与可选 NPC 云端搭车仍依赖既有 2.0 管线，尚未完成职责拆分 |

不能用百分比衡量完整度，也不能将模型自然度、Android 真机或用户个人 Worker 的验收替换成单元测试通过。

## 本轮修复

- 手机上下文不再调用完整私聊系统提示词，避免私聊工具/输出协议与手机 JSON 任务争抢职责；统一调用 ContextBuilder 与 chatContextRange，尊重历史断点、关键词世界书、消息拒收和角色/群聊边界。
- 移除各入口对共享上下文的任意截断和额外手工世界书拼接；社交快照去掉重复的原始消息拼接，避免图片资源进入文本上下文。资料/头像偏好入口也接同一人物背景。
- 日程纯渲染层对前台与 Worker 共用，统一声明计划与实际经历优先级。日程关闭不影响独立保存的生活经历。
- 私聊镜像保持数据库发送顺序，云端补收时间较早不再重排对话；语音/图片等保存为可读描述，不把资源地址当聊天文字。
- 手机后台关闭/重开、设置代次变化、调用方取消均中止旧请求；旧 Android 缺少 AbortSignal.any 时仍合并取消信号。等待 KeepAlive 的阶段取消，不再启动网络。手动请求不随后台开关被误取消，无自动重试。
- 朋友圈上下文准备期间撤权又重开，不得获得新授权或消耗新额度。手机 UI 保留既有布局和入口。

## 验证及边界

- 离线使用模拟 API 验证权限、在途/准备阶段取消、迟到结果、世界书/历史范围、镜像、日程开关、时区、群聊隔离、学习室与 2.0 相关回归；不读取或调用用户付费 Key。
- 扩大运行的 120 个文件/1350 项中，11 项失败均在未修改基线复现：`amsg2Timezone` 1 项、`amsgInstantChat.wiring` 4 项、`amsgStateSync.gaps` 2 项、`chatPrompts.firePack` 的退役彼方/SAR 4 项。日程渲染相关断言已随新语义更新。另行排除上述已证实旧失败，116 文件/1279 项通过；补充新撤权测试后，最终复跑 116 文件/1280 项全部通过；发布前置 8 文件/85 项也全部通过，生产构建成功。构建会改变生成产物的格式，源文件格式守卫在恢复本任务无关产物后复测。
- `scheduleAppearance` 两项颜色断言在基线同样失败；未修改日程视觉。全项目类型检查与基线均为 824 项诊断；去除行号与目录差异后无新增诊断，不能宣称全仓类型检查全绿。
- 构建会重新生成 Worker 包。共享日程渲染修正要在个人 Worker 更新后才影响其服务端生成；测试站更新不等于已更新用户自己的 Worker，本轮不操作个人部署或凭据。
- 发布验收须核对指定测试站 `preview-source.json` 的 sourceCommit 和实际运行的 build，并检查聊天、手机及日程入口截图。最终状态以本次交付说明为准。
